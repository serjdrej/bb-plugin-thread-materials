## Files

Search by name or path and filter by extension. Group files by type and sort each group by name, date, or size. Turn grouping off for a single sorted list. Select a file to open it in BB's preview.

## Images

Browse thumbnails from thread storage and supported local attachments. Click a thumbnail to view the image at full size.

## Links

Search the web links collected from visible user and assistant messages. Open a link in BB or select **К сообщению** to jump back to its source. Select **Загрузить старые** to search earlier messages.

## Requirements

Requires BB 0.50.1 or later with Plugin SDK 0.6.157 or later. The panel uses Russian labels. File dates and sizes depend on metadata from the thread's host.
